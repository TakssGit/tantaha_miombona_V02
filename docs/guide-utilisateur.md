# Guide utilisateur — résumé

## Page publique

La page `/` présente l'établissement, le circuit court, les acteurs, la qualité et le catalogue des produits finis.

## Producteur

Le Producteur connecté utilise **Mon espace producteur** pour consulter sa fiche et enregistrer ses prévisions de récolte.

## Point focal

Le Point focal gère uniquement les producteurs qui lui sont affectés. Il peut créer une fiche producteur et saisir une prévision pour un producteur qui ne peut pas se connecter lui-même.

## Distributeur / revendeur

Le Distributeur consulte les produits disponibles, saisit les quantités souhaitées et envoie une commande. Il suit ensuite le statut de ses commandes.

## Utilisateurs internes

Les modules métier restent disponibles selon le rôle : Gestionnaire, Qualité, Production, Commercial et Administrateur.
