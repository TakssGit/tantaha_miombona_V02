# Guide administrateur — résumé

L'Administrateur peut :

- approuver ou rejeter les demandes de compte Producteur/Distributeur ;
- gérer les utilisateurs internes et leurs rôles ;
- activer/désactiver un compte avec protections sur le dernier ADMIN ;
- traiter les demandes de réinitialisation de mot de passe ;
- lier un compte Producteur à une fiche Producteur ;
- affecter des producteurs à un Point focal ;
- consulter les prévisions, commandes, journaux de sécurité et d'administration ;
- accéder à tous les modules métier.

Ne jamais utiliser `db:reset` sur une base réelle sans sauvegarde.
